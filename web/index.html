cardputerOS flasher

Install cardputerOS on an M5Stack Cardputer ADV straight from the browser: no tools to install.

This browser cannot talk to USB serial devices. Use Chrome, Edge or Opera on a desktop computer. Installing only works over HTTPS (or on localhost).

How to install

  1. Connect the Cardputer to this computer with a USB-C data cable and switch it on.
  2. Click Connect and install and pick the Cardputer's serial port (usually “USB JTAG/serial debug unit”).
  3. Choose Install cardputerOS. Leave Erase device unticked to keep your notes, journal, SSH key and settings.
  4. Wait until it reports success, then press the reset button (or switch the Cardputer off and on).

If no port shows up, or the connection fails: switch the Cardputer off, hold G0 while switching it on (download mode), then try again.

Updating

Installing over an existing cardputerOS only replaces the system. Notes, journal days, Wi-Fi networks and the SSH key live in a separate part of the flash and are kept, unless you tick Erase device, which wipes everything.

Other ways

The firmware images are also attached to every GitHub release, for flashing with esptool: esptool.py --chip esp32s3 write_flash 0x10000 cardputerOS-vX.Y.Z-app.bin updates an installed system; the -full.bin image goes to 0x0 for a first install (it resets the settings).
